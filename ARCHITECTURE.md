# Архитектура проекта (Простыми словами)

Этот проект написан на Python (сервер) и JavaScript (интерфейс). Если вы привыкли к n8n (где всё состоит из блоков/нод), то здесь логика такая же, просто она описана кодом.

## Аналогия с n8n

В n8n у вас есть **Webhook-нода** (которая принимает запросы), затем **ноды обработки**, **нода отправки в OpenAI**, и **нода ответа**. 

В нашем коде всё то же самое:
1. **Webhook / Триггер** — это функции с декораторами `@app.post(...)` в файле `backend/main.py`. Они «слушают» запросы от браузера.
2. **Обработка** — это обычные функции Python в том же `main.py` (например, получение аудио и его сохранение).
3. **HTTP Request / AI** — это вызовы API AssemblyAI и OpenRouter внутри функций `transcribe_audio()` и `generate_protocol()`.

## Структура папок

### 1. `backend/` (Сервер / "Под капотом")
Это сердце приложения, которое запускается в Docker-контейнере.
- `main.py` — главный файл. Здесь описаны все маршруты (URL), обработка аудио, запросы к нейросети и генерация `.docx`. Это ваш главный «workflow» в коде.
- `data/` — папка, где сервер временно сохраняет файлы и базу данных `jobs.db` (база нужна, чтобы очередь задач не терялась при перезагрузке).

### 2. `backend/static/` (Фронтенд / "Внешний вид")
Это то, что загружается в браузере у пользователя. 
- `index.html` — скелет страницы, разметка (кнопки, текст).
- `style.css` — дизайн, цвета, отступы, анимации.
- `app.js` — логика кнопок (что происходит при нажатии «Загрузить», как работает плеер и как браузер отправляет запрос на сервер).

### 3. `prompts/` (Промпты для нейросетей)
- `system-protocol.md` — текстовый файл с инструкциями для искусственного интеллекта (как писать протокол, какие ФИО судей использовать). Вы можете редактировать этот текст как обычный документ, и ИИ сразу начнет работать по новым правилам без перезагрузки сервера.

## Как проходит полный цикл работы (Flow)

1. **Браузер (app.js)**: Пользователь выбирает файл `Козлов.m4a` и нажимает кнопку. Скрипт отправляет этот файл на сервер (как если бы вы загрузили файл через веб-форму в n8n).
2. **Сервер (main.py -> `@app.post("/upload")`)**: Принимает файл, сохраняет его в папку `data/media/` и ставит в очередь (базу данных). Возвращает браузеру `job_id` (номер задачи).
3. **Сервер (Фоновая задача)**: 
   - Отправляет аудио в **AssemblyAI** (получает текст со спикерами).
   - Берет текст и отправляет его в **OpenRouter/LLM** вместе с инструкцией из `prompts/system-protocol.md`.
   - Получает готовый текст протокола и сохраняет результат в базу.
4. **Браузер (app.js)**: Каждые пару секунд спрашивает у сервера: *"Задача готова?"*. Как только сервер отвечает *"Да, вот текст"*, браузер генерирует кнопку скачивания `.docx`.

**Итог:** Всё, что вы раньше собирали стрелочками в n8n, здесь собрано в функции внутри `main.py` и `app.js`, что дает гораздо больше контроля, скорости и гибкости интерфейса.
